# FarmPlug Farmer Android App

Farmer-first Flutter Android client for FarmPlug AI.

## Backend

This app is designed to use the existing FarmPlug Next.js API and Supabase authentication/backend. It must never contain Supabase secret/service keys.

## Planned farmer flow

1. Sign in with Supabase
2. View farmer dashboard
3. Create and manage produce listings
4. Use FarmPlug AI Decision Center
5. View buyer/quote signals
6. Track orders and fulfilment
7. View collection/logistics status

The repository workflow generates the Android project and release APK in CI.
