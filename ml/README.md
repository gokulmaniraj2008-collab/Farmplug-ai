# FarmPlug AI ML service

This directory is the model layer described by the product specification. UI values must never be presented as validated forecasts unless generated by this pipeline and backed by stored evaluation metrics.

Pipeline: ingestion -> cleaning -> feature engineering -> time-aware validation -> training -> backtesting -> forecast -> confidence -> persisted model metadata.

The reference implementation uses Python, pandas, numpy and scikit-learn. It supports price and demand regression when enough historical observations exist. It refuses to train when the dataset is too small or lacks a usable date/target column.

Required output metadata: model_version, dataset_version, forecast horizon, prediction, interval, confidence, MAE, RMSE and MAPE when appropriate.
