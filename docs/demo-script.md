# FarmPlug AI SIH Demo Script

## 2-minute judge flow

1. **Problem (15s)** — Farmers can have fragmented supply while buyer demand and selling windows are difficult to coordinate.
2. **Farmer (20s)** — Open the Farmer PWA and create a produce listing with crop, quantity, quality and location.
3. **Decision Center (20s)** — Enter the same crop and quantity to show the explainable prototype decision output. State that it is a demonstration and requires validation.
4. **Buyer (20s)** — Open the buyer view, create/select an open requirement and show a matching supply listing.
5. **Quote (15s)** — Send the quote request and switch to the farmer view to accept it.
6. **Order (15s)** — Show that accepting the quote creates a confirmed order and reserves the supply listing.
7. **Logistics (10s)** — Generate a route from supply location to delivery location using the live routing endpoint.
8. **Close (5s)** — “FarmPlug does not only list agricultural produce; it converts fragmented supply into a verified, buyer-ready order.”

## Judge-safe wording

Use “prototype”, “demonstration”, “estimate”, and “requires validation” where appropriate. Do not claim guaranteed prices, buyer commitments, scientific accuracy, or production-grade logistics SLAs.
